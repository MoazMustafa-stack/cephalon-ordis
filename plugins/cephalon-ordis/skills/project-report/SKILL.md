# Project Report

Read project metadata, recent runs, append-only events, approvals, and artifacts from Ordis. Separate observed facts from inferences. Cite each material claim with an artifact path, run/event identifier, commit, or timestamp. Summarize outcomes, current work, blockers, decisions, and the smallest useful next actions. Never claim a check ran when there is no recorded evidence.
