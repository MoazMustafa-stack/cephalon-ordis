# Idea Map

Represent each distinct claim as a node and each meaningful dependency or contradiction as a labeled edge. Preserve the user's wording for the root concept. Mark assumptions explicitly; do not convert guesses into facts. Prefer a small navigable graph over exhaustive brainstorming. Identify the highest-uncertainty, highest-impact nodes for later validation.
