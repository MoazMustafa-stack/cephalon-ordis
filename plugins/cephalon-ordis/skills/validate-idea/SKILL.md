# Validate Idea

State the claim, decision, threshold, and disconfirming result before evaluating evidence. Record source, capture time, and limitations for each item. Score evidence quality separately from whether it supports the idea. Return supported, contradicted, or inconclusive; never collapse missing evidence into support. Propose the cheapest ethical next test for unresolved high-impact claims.
