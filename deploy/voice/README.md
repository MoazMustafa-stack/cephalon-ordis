# Local voice services

Install whisper.cpp, Piper, and openWakeWord locally. Store model files only in `E:\Cephalon-Ordis\data\models` on Windows or `/srv/cephalon-ordis/data/models` on Arch. Configure loopback-only adapters for the coordinator's transcribe, speak, and voice WebSocket routes. Cloud speech fallbacks are intentionally unsupported.
